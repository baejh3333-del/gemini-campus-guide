3. 버튼 — 원형 기하 + 누름 반응

Primary · 눌리면 scale(.968) + 그림자 수축 + 중심에서 흰빛 링

Go · 외부 창을 여는 동작에만

Ghost 는 반투명 + 블러. 비활성은 그림자를 완전히 뺍니다

모서리 12px → 999px. 원이 기본 도형이라는 원칙을 버튼·칩·배지에 적용했습니다. 카드만 20px 라운드를 유지합니다.

4. 모션 — 장식이 아니라 안내

Kinetic — 등장 · 전환
cubic-bezier(.2, 0, 0, 1) · 320ms
Press — 누름 · 되돌림
cubic-bezier(.3, 0, .2, 1) · 200ms
Linear — 쓰지 않음
linear · 기계적으로 읽힘

prefers-reduced-motion 에서 모든 전환을 0.01ms 로 낮춥니다.

5. 스크롤 최하단 이펙트

다 읽었어요 — 다음으로

바닥 64px 안으로 들어오면 블룸이 차오르고 칩이 떠오릅니다.

1남은 스크롤이 64px 미만일 때만 상태를 바꿉니다. 임계값을 넘을 때 한 번만 setState 하므로 스크롤이 끊기지 않습니다.
2블룸 opacity 0→1 · 700ms, 칩 translateY(10px)→0 · 600ms. 둘 다 Kinetic 커브.
3동시에 하단 다음 버튼의 그림자가 짙어집니다. "여기가 끝, 다음은 저기" 를 색이 아니라 빛으로 알려주는 장치입니다.
