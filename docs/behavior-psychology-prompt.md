# 행동심리학으로 나를 추리하는 AI — 웹페이지 구성

## 카드에 넣을 내용

- 제목: 행동심리학으로 나를 추리하는 AI
- 설명: 왜 나는 꼭 그 순간에 미룰까? 다섯 가지 질문에 답하고, 내 선택과 습관에 반복되는 패턴을 단서와 함께 발견해 보세요.
- 카테고리: 일상·자기관리
- 유형: 복사해서 쓰는 프롬프트
- 시각 요소: 사용자가 제공한 흑백 인물 썸네일을 `/behavior-psychology-detective.png`로 사용한다. 세로형 원본의 문구가 잘리지 않도록 전체 이미지가 보이게 표시한다.

## 상세 페이지에 넣을 내용

기존 상세 페이지의 순서를 그대로 사용한다.

1. **어떤 기능이에요?** — 카드 설명을 보여 준다.
2. **이렇게 쓰세요** — 프롬프트 복사 → 최근 행동에 관한 질문 5개에 하나씩 답하기 → 추리를 확인하고 일주일 실험 고르기의 세 단계로 안내한다.
3. **바로 쓰는 프롬프트** — 전체 지시문과 기존 복사 버튼을 제공한다. 사용자가 빈칸을 미리 채우지 않아도 첫 질문부터 시작되도록 구성했다.

프롬프트의 전체 원문은 `content/behavior-psychology-prompt.ts`에서 관리하고, `content/prompts.ts`의 `behavior-psychology-detective` 항목이 이를 불러온다. 카드 설명과 실제 사용 안내는 목록 항목에서 관리한다. 본문을 여러 파일에 복제하지 않는다.

## 상세 프롬프트의 구성

GitHub의 SKILL.md처럼 메타데이터와 실행 지침을 갖춘 원본 창작 프롬프트다. 외부 GitHub 저장소에서 가져온 스킬로 표시하지 않으며, 기존의 프롬프트 복사 기능을 그대로 사용한다.

- 역할, 성공 기준, 적용 범위, 개인정보와 입력 자료의 경계
- 기본 인터뷰·자료 선입력·조기 분석·심층 탐색·종료 처리
- 다섯 질문 각각의 목적, 기본 질문, 수집할 단서, 피해야 할 유도, 예외 대응
- 상황·행동·직후 결과를 정리하는 사건 기록과 대안 가설 비교 절차
- 반대 사례 반영, 근거 수준 표현, 심리 개념 사용과 오용 방지 기준
- 최종 보고서의 항목·표·분량·피드백 질문
- 일주일 실험의 비교 방법, 기록, 해석 한계, 축소·중단 조건
- 맞지 않는 추리에 대한 수정 절차와 좋은 해석·나쁜 해석의 가상 예시
- 출력 전 품질 점검과 바로 실행할 첫 응답

기본 질문은 5개이며, 행동을 전혀 알 수 없을 때만 보충 질문을 최대 2회 허용한다. 별도의 심층 탐색은 사용자가 요청했을 때 추가 질문을 최대 3개 진행한다.

## 사용자가 경험하는 흐름

웹페이지에서 프롬프트를 복사해 Gemini나 ChatGPT에 붙여넣는다. AI는 최근 미룬 일, 자발적으로 계속한 일, 망설인 선택, 부탁이나 의견 차이에 반응한 순간, 앞선 패턴과 반대되는 경험을 한 번에 하나씩 묻는다.

답변을 마치면 한 문장 요약, 행동의 단서와 가능한 해석, 다른 설명, 상황에 따른 장단점, 일주일 행동 실험을 받는다. 사용자는 맞지 않는 부분을 알려 해석을 수정할 수 있다. 질문을 건너뛰거나 중간에 분석을 요청할 수도 있다.

## 실제 반영 방식

- `LIBRARY_PROMPTS`의 첫 항목에 추가해 기존 목록과 ‘일상·자기관리’ 필터에서 노출한다.
- 상세 경로는 `/prompts/behavior-psychology-detective`다. 기존 동적 상세 페이지가 제목, 설명, 사용 순서와 본문을 표시한다.
- 기존 복사 기능을 재사용한다. 웹사이트 안에서 직접 심리 질문을 진행하거나 답변을 수집하는 기능은 추가하지 않는다.
- 연결할 실제 릴스나 카드뉴스가 아직 없으므로 원본 링크를 등록하지 않는다.
- 소개 문구에 정확도, 성격 판정, 숨겨진 본심을 알아낸다는 약속을 넣지 않는다. 추리는 사용자가 제공한 행동에 근거한 가설로 제시한다.

이 문서와 콘텐츠 추가는 로컬 프로젝트에 반영한 내용이며, 공개 사이트 배포는 별도다.
