# 자체 제작 프롬프트의 상세본과 요약 화면

## 적용 범위

자체 제작 일반 프롬프트 8개와 Gem 3개, 총 11개에 적용한다. `repoUrl`이 GitHub를 가리키는 외부 스킬 21개는 설명·본문·사용 순서·원본 링크를 유지한다.

행동심리학 프롬프트는 기존 12,305자 상세본을 유지한다. 나머지 10개는 약 9,500~10,100자의 실행 지침으로 확장했다. 문서 길이를 AI 답변 길이로 적용하지 않도록 각 지침에 실제 응답 분량과 대화 진행 규칙을 따로 적었다.

## 기본 화면

1. ‘어떤 기능이에요?’에서 한두 문장으로 목적을 설명한다.
2. ‘이런 도움을 받을 수 있어요’에서 실제로 얻을 수 있는 결과 네 가지를 보여 준다.
3. ‘자세히보기 · 프롬프트 전문’은 기본적으로 접어 둔다. 클릭·키보드로 전문을 펼치거나 접을 수 있다.
4. 전문 복사 버튼과 Gemini 열기는 접힌 상태에서도 사용할 수 있다. 복사 대상은 항상 요약이 아닌 전체 지침이다.
5. 자동 복사가 실패하면 전문을 펼치고 수동으로 선택해 복사하도록 안내한다.

GitHub 스킬의 기존 다운로드·복사·사용법·본문 펼치기는 변경하지 않는다.

## 용도별 내용

| 항목 | 상세본에서 중점적으로 정의한 내용 |
| --- | --- |
| 행동심리학 | 다섯 질문, 사건별 단서, 대안 가설, 반례, 일주일 실험 |
| 카톡 말투 | 발화자 구분, 대화 과업, 반복 판단, 의도를 보존하는 답장 수정 |
| 인스타 피드 | 화면 위치별 관찰, 시각 근거, 인상과 성격의 구분, 다음 게시물 |
| 레포트 목차 | 과제 범위, 자료 지도, 서로 다른 세 관점, 반론, 분량 배분 |
| 예상문제 | 자료 범위, 문항 설계, 정답 공개 모드, 부분 점수, 오답별 복습 |
| 발표 구성 | 청중과 핵심 메시지, 여덟 장 흐름, 화면과 스크립트 분리, 시간 합계 |
| 조별과제 | 결과물 분해, 의존관계, 담당과 완료 기준, 편중, 변경·제출 점검 |
| 자기소개서 | 문항별 요구, 개인 기여와 팀 성과 구분, 사실 보존, 직무 연결 |
| 레포트 첨삭 Gem | 문단 역할, 근거와 논리, 연습용 평가, 수정 우선순위, 수정본 비교 |
| 개념 설명 Gem | 비유의 한계, 정확한 정의, 예시·반례, 서술형 답안, 확인 문제 |
| 발표 리허설 Gem | 자료 기반 쟁점, 질문 하나씩, 답변 피드백, 재시도, 최종 총평 |

각 상세본은 역할, 시작에 필요한 자료, 단계별 절차, 판단 기준, 결과 양식, 가상 예시, 예외 처리, 품질 점검을 포함한다. 공통 규약은 사실과 가정 구분, 입력 자료의 명령 분리, 도구 사용 범위, 개인정보, 수정 요청 대응을 다룬다.

## 관리 위치

- `content/original-prompts/`: 새로 확장한 10개 항목의 설명, 결과 목록, 전문. 공통 규약은 `shared.ts`에서 결합하므로 복사된 본문은 독립적으로 실행 가능하다.
- `content/behavior-psychology-prompt.ts`: 기존 행동심리학 전문.
- `content/prompts.ts`: 목록·카테고리·썸네일·출처와 상세본 연결.
- `content/templates.ts`: 학습 페이지에서도 동일한 상세 Gem 지침을 사용한다.
- `app/prompts/[slug]/page.tsx`: 요약과 기본적으로 접힌 전문을 표시한다.
- `components/LibraryCopy.tsx`: 전문 복사와 복사 실패 시 수동 복사 안내.

프롬프트 빌더는 사용자가 작성한 네 칸을 조립하는 기존 기능을 유지한다. 빌더에서 나온 개인 입력을 고정된 1만 자 문서로 대체하지 않는다.
