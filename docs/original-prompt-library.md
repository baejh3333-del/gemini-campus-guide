# 자체 제작 프롬프트의 상세본과 요약 화면

## 적용 범위

자체 제작 일반 프롬프트 16개와 Gem 3개, 총 19개에 적용한다. `repoUrl`이 GitHub를 가리키는 외부 스킬 21개는 설명·본문·사용 순서·원본 링크를 유지한다. 전체 저장소는 40개다.

행동심리학 프롬프트는 기존 12,305자 상세본을 유지한다. 나머지 10개는 약 9,500~10,100자의 실행 지침으로 확장했다. 문서 길이를 AI 답변 길이로 적용하지 않도록 각 지침에 실제 응답 분량과 대화 진행 규칙을 따로 적었다.

추가한 캠퍼스·일상 주제 8개도 각각 약 9,500~9,900자의 지침이다. 사용자가 제공한 8장의 이미지를 `public/prompt-thumbnails/`에 원본 그대로 저장하고, 전체 이미지가 잘리지 않게 표시한다. 카드에서는 Next.js 이미지 최적화를 통해 화면 크기에 맞는 이미지를 지연 로딩한다.

## 기본 화면

1. ‘어떤 기능이에요?’에서 한두 문장으로 목적을 설명한다.
2. ‘이런 도움을 받을 수 있어요’에서 실제로 얻을 수 있는 결과 네 가지를 보여 준다.
3. ‘자세히보기 · 프롬프트 전문’은 기본적으로 접어 둔다. 클릭·키보드로 전문을 펼치거나 접을 수 있다.
4. 전문 복사 버튼과 Gemini 열기는 접힌 상태에서도 사용할 수 있다. 복사 대상은 항상 요약이 아닌 전체 지침이다.
5. 자동 복사가 실패하면 전문을 펼치고 수동으로 선택해 복사하도록 안내한다.

GitHub 스킬의 기존 다운로드·복사·사용법·본문 펼치기는 변경하지 않는다.

## 관리 위치

- `content/original-prompts/`: 새로 확장한 10개 항목의 설명, 결과 목록, 전문. 공통 규약은 `shared.ts`에서 결합하므로 복사된 본문은 독립적으로 실행 가능하다.
- `content/behavior-psychology-prompt.ts`: 기존 행동심리학 전문.
- `content/campus-prompts.ts`: 새 주제 8개의 제목·카테고리·썸네일·사용 순서를 연결한다. 본문은 `content/original-prompts/`의 주제별 파일을 사용한다.
- `content/prompts.ts`: 목록·카테고리·썸네일·출처와 상세본 연결.
- `content/templates.ts`: 학습 페이지에서도 동일한 상세 Gem 지침을 사용한다.
- `app/prompts/[slug]/page.tsx`: 요약과 기본적으로 접힌 전문을 표시한다.
- `components/LibraryCopy.tsx`: 전문 복사와 복사 실패 시 수동 복사 안내.

프롬프트 빌더는 사용자가 작성한 네 칸을 조립하는 기존 기능을 유지한다. 빌더에서 나온 개인 입력을 고정된 1만 자 문서로 대체하지 않는다.

## 동작 범위와 공식 참고

이 사이트는 프롬프트를 제공한다. 카드 추가만으로 사용자 계정에 연결하거나 일정을 등록하거나 매일 공고 알림을 만들지 않는다. 복사해 실행한 AI에 실제로 제공되는 도구와 사용자가 지정한 범위에 따라 진행한다. 사진·회고도 사용자가 고른 자료로 시작하며 계정 전체 접근을 전제하지 않는다.

2026-11-09 기준으로 아래 공식 자료를 확인해 캘린더 형식과 시험 기준의 적용 시점을 반영했다. 이후 실행 시에도 실제 자료와 응시일에 맞는 안내를 확인하도록 지시문에 명시했다.

- [Google Calendar 일정 가져오기](https://support.google.com/calendar/answer/37118?hl=ko): 컴퓨터에서 ICS·CSV를 가져오는 방식과 가져오기 이후 동기화의 구분.
- [iCalendar RFC 5545](https://www.rfc-editor.org/rfc/rfc5545): 일정 파일의 구조와 날짜·시간 표현.
- [대한상공회의소 컴퓨터활용능력 관련자료](https://license.korcham.net/co/examguide04.do?cd=0103&mm=202&pg=1): 시행 기간이 다른 출제기준을 응시일에 맞춰 선택.
- [대한상공회의소 시험 안내](https://ml.korcham.net/co/examguide.do?cd=01&jmcd=0103): 급수와 필기·실기를 구분해 계획.

## 전문가형 상담·코칭 프롬프트 14개

`content/expert-prompts.ts`(메타데이터)와 `content/expert-prompt-bodies.ts`(프롬프트 전문)에 있다. 연인 갈등 분석, 심리상담, 관계 결정 코치, 진로 면담, 노동·임대차 법률 보조, 시선 불안 코치, 거절·사과 코치, 면접관 시뮬레이터, 부모님 갈등 중재, 이별 회복, 학습 설계, 협상 코치, 사회초년생 재무 점검, 진료 전 준비 도우미다.

- 모든 프롬프트에 위기 신호(자해·폭력·응급) 안내 규칙이 들어 있다. 연락처(109, 1577-0199, 1366, 1388, 132, 1350, 1332)는 공개 전과 정기적으로 최신 여부를 확인한다.
- 썸네일은 아직 없다. 이미지 자리에 `thumbnail.placeholder`로 넣을 그림을 글로 적어 두었고, 카드에서는 점선 박스 안에 "썸네일 자리" 문구로 보인다.
- 썸네일이 준비되면 `public/prompt-thumbnails/`에 파일을 넣고, 해당 항목의 `thumbnail`에 `src`와 `alt`를 채운 뒤 `placeholder`를 지운다. `src`가 있으면 placeholder는 표시되지 않는다.
